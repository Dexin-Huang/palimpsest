# Historical Chinese Character Localization Autoresearch Protocol

Status: development experiment; production is unchanged.

## Goal

Find every visible character instance on a historical Chinese document page
without identifying or transcribing it. The candidate output is geometry:
tight character bounding boxes today, with lassos or masks evaluated separately
when available. Character identity and page text are outside this experiment.

The local optimization objective is lexicographic:

1. zero missing, failed, or fabricated pages;
2. maximize unlabeled character-detection F1 at IoU 0.50;
3. maximize AP50 and recall without an unacceptable precision loss;
4. prevent a material regression in any protected source corpus;
5. among statistically indistinguishable candidates, prefer lower cost and
   latency.

No transcription score can qualify or reject a candidate in this experiment.
The external SOTA gate must come from a benchmark that evaluates the same
unlabeled character-localization task; OCR transcription results are not
comparable evidence.

## Evidence tiers

### Development

`fetch.py mthv2` deterministically selects 80 pages from each MTHv2 source corpus from the official training split. Selection is by SHA-256 rank of the source path, not by model performance. This 240-page set is the only tuning set. A 36-page smoke slice (the first 12 ranked cases per corpus) is used for fast rejection.

### Qualification

The official 800-page MTHv2 test split is immutable and sealed from tuning. Run it only after a challenger wins on the full development set. Report each source corpus separately (`TKH`, `MTH1000`, and `MTH1200`) as protected slices.

### Production protection

The repository's frozen 28-folio `experiments/testset/manifest.json` remains a
visual and operational regression set. It has no complete independent
character-location gold, so it cannot authorize an accuracy claim. It checks
that a challenger still handles the manuscript/archive regimes Palimpsest
actually serves.

## Data decisions

| Dataset | Use | Decision |
|---|---|---|
| MTHv2 | development and first external qualification | Adopt. It has manually annotated page images, text lines, character labels, and boxes; its official split and source styles are public. The terms restrict it to academic/non-commercial research. |
| M5HisDoc | second external qualification | Do not fabricate access. The official repository requires an application and legal commitment. Add it only after access is approved, preserving its official split. |
| HisDoc1B | possible training corpus | Never use as evaluation gold. It contains about 3.01 million pages and 2.44 billion annotations, but most annotations are generated by the authors' pipeline; only the validation sample was manually checked. |
| Kuzushiji Page Dataset | optional cross-script stress test | Not a Chinese SOTA gate. Its public COCO annotations and CC BY-SA 4.0 license make it useful for testing localization generality after the Chinese objective works. |

MTHv2 source identities are pinned in `fetch.py`:

- repository commit `c9bd9b1b4ee999dd0acafd226a8a901a7088d980`;
- official `test.txt` (800 pages: 249 TKH, 223 MTH1000, 328 MTH1200);
- official Google Drive archive `TKHMTH2200.zip` (4,932,243,090 bytes).

Downloaded assets and generated predictions live below ignored `scratch/ocr_benchmark/`. Manifests contain SHA-256 hashes for every extracted source and ground-truth file.

## RF-DETR development candidate

The first trained challenger is `rf_detr/one-class-tiled-v1`:

- model: RF-DETR Nano 1.8.3 (Apache-2.0);
- class set: one unlabeled `character` class;
- training source: 90 MTHv2 training pages, 30 per corpus, selected by
  source-path SHA-256 after reserving the first 80 per corpus for development;
- development source: the frozen 36-page smoke manifest, followed by the
  immutable 240-page development manifest after the smoke gate passed;
- qualification source: the sealed official 800-page MTHv2 test split;
- source tiles: 512 by 512 pixels with 96-pixel overlap;
- tile labels: retain boxes with at least 80% of their source area visible;
- training resolution: 512 pixels;
- training: at most 5 epochs with early stopping, batch size 1, gradient
  accumulation 8, learning rate 0.0001;
- environment: Python 3.12, PyTorch 2.7.0 with CUDA 11.8;
- inference threshold: 0.25 initially; 0.40 in the separately fingerprinted
  confidence-calibration challenger;
- tile deduplication: class-agnostic NMS at IoU 0.40;
- budget: no paid model calls.

MTHv2 human boxes are sufficient for this candidate. Gemini or another vision
model may create pre-annotations for additional production-regime pages, but
model output is never evaluation gold. Such boxes enter training only after a
human reviews every instance, adds misses, removes junk, and records the
reviewer and source-model identity. The first RF-DETR run does not mix
pseudo-labeling with the detector change.

Development result: the candidate scored F1 0.964998 and AP50 0.984581 on all
36 frozen pages. Its mean paired per-page F1 improvement over
`separation2/current-zero-cost` was +0.280126 with 95% bootstrap CI
[0.211781, 0.353389], and every protected corpus improved. This authorizes the
next development experiment; it does not authorize production or qualification.
The immutable report is
`scratch/ocr_benchmark/runs/rfdetr-one-class-tiled-v1-mthv2-dev36/report.json`.

The smoke winner was then run on all 240 reserved development pages
(80 per corpus; manifest SHA-256
`fa8521356d1b2bb3b43ff666a9c8ac021e0aeb2ab1eb4e42e13c45fb746d61c2`).
At threshold 0.25 it scored F1 0.964870 and AP50 0.980649.

Confidence 0.40 was selected on the original 36-page smoke set and validated
without further tuning on the other 204 pages. On those untouched pages, F1
improved from 0.964846 to 0.976407; mean paired per-page F1 improved by
+0.010955 with 95% bootstrap CI [0.007613, 0.014565]. MTH1000 and MTH1200
improved by +0.016077 and +0.018902 F1; TKH changed by -0.001236, within the
0.01 protected-slice hard limit. The confidence candidate fingerprint is
`5d3b0a08e0470537af7b719e2113f142681711117708f403bea09632b9de5b8a`.

Across all 240 development pages, threshold 0.40 scored precision 0.979411,
recall 0.974068, F1 0.976732, and AP50 0.971313. The zero-cost baseline scored
F1 0.659016 and AP50 0.588276. Mean paired per-page F1 improved by +0.299992
with 95% bootstrap CI [0.272858, 0.328505], and every source corpus improved.
This is a development winner only. Qualification remains unrun and production
remains unchanged.

## Data-scale maximization experiment

Goal: maximize the fixed localization objective without tuning on qualification
or changing production. The next treatment is named
`scale300-fixed-epochs-seed361004-v1`.

Hypothesis: under the same pinned initialization, runtime, seed, model,
optimization settings, tiling, and exactly five epochs, expanding human-labeled
MTHv2 training data from 90 to 300 pages (30 to 100 per corpus) improves
fixed-threshold localization. The proportional increase in tiles and optimizer
updates is explicitly part of this operational treatment; this experiment does
not claim to isolate unique-page diversity at a fixed update budget.

Controls and immutable dependencies:

- train a new 90-page control and 300-page challenger with seed `361004`;
- use corpus-local source-path-hash ranks 81-110 for the control and 81-180
  for the challenger; the control is a strict subset of the challenger;
- use RF-DETR Nano pretrained weights SHA-256
  `d8d6b9ee57d4d0ed2b1f305163624712a0532cb7bce0c747317984fc5457440d`;
- freeze the exact Python, RF-DETR, PyTorch, torchvision, CUDA, hardware, and
  candidate-source identities before training;
- use the identical 36-page validation manifest SHA-256
  `287ab7dfe0235e5f3a82b7acd82e4eeefbdd58cdc3ff1612a9d5c3112dcafb08`;
- train exactly five epochs with early stopping disabled and select
  `checkpoint_best_total.pth` in both matched arms;
- preserve 512-pixel tiles, 96-pixel overlap, 80% box visibility, batch size
  1, gradient accumulation 8, learning rates, fixed step schedule, disabled
  multi-scale training, gradient checkpointing, threshold 0.40, and NMS 0.40;
- verify zero case, source-path, image, text-line-label, and character-label
  identity collisions between training and all 240 development pages;
- use new acquisition, tile-dataset, run, prediction, and report paths.

MTHv2's official split is random by page and does not provide authoritative
book-group identities. This experiment therefore supports page-level MTHv2
development claims only; it does not claim unseen-book generalization. A later
M5HisDoc or production-regime suite must group by independently established
source book.

Run the frozen 36-page smoke gate first. Run all 240 development pages only if
coverage is complete, the challenger improves the matched seeded control, and
no corpus regresses by more than 0.01 F1. Keep the 300-page candidate only if
the full paired-F1 confidence interval is positive against the seeded control,
it also beats the frozen operational champion fingerprint
`5d3b0a08e0470537af7b719e2113f142681711117708f403bea09632b9de5b8a`,
coverage is 1.0, and every protected-corpus delta is at least -0.01.
Qualification remains sealed; no production or paid command is authorized.

Outcome: the predeclared five-epoch, threshold-0.40 challenger failed the smoke
gate. It scored F1 0.940577 versus 0.978532 for the matched seeded control;
mean paired per-page F1 changed by -0.037728 with 95% bootstrap CI
[-0.042737, -0.032388], and all three protected corpora regressed. The full
gate was not run for this rejected configuration.

A bounded training-trajectory calibration then selected the regular epoch-zero
checkpoint and threshold 0.31 on the same 36-page selection set. This separate
candidate scored F1 0.981868 and beat the frozen champion by mean paired
per-page F1 +0.003414 with 95% CI [0.000516, 0.006318]. Without further
tuning, it scored F1 0.978299 and AP50 0.976607 on the untouched 204 pages;
mean paired F1 improved by +0.002160 with 95% CI [0.000527, 0.003898].
Protected-corpus deltas were MTH1000 +0.003556, MTH1200 -0.000311, and TKH
+0.001804.

Across all 240 development pages, the calibrated candidate scored precision
0.977391, recall 0.980306, F1 0.978846, and AP50 0.977268. Mean paired F1
improved over the prior champion by +0.002348 with 95% CI
[0.000842, 0.003881], and every protected-corpus delta was nonnegative. Its
checkpoint SHA-256 is
`812d5bfc19f74a301a5eb72a147a35105d700f804948240c783159e8c9747085`;
the prediction fingerprint is
`6a72b1d1562d0e90b3a850f9f800796177c6693ce045baa98167e16f27c05604`.
This is the new development champion, not a qualified or production candidate.

## Low-contrast augmentation experiment

Goal: improve recall on the pale, irregular MTH1000 residual slice without
changing the data split, model, training exposure, or inference policy.

Hypothesis: one epoch of deterministic training on the same 300 human-labeled
pages with only `RandomBrightnessContrast` augmentation
(`brightness_limit=0.10`, `contrast_limit=0.10`, `p=0.30`) improves paired
full-page localization over the calibrated epoch-zero champion.

Immutable controls:

- baseline checkpoint SHA-256
  `812d5bfc19f74a301a5eb72a147a35105d700f804948240c783159e8c9747085`;
- challenger starts from the same pretrained RF-DETR Nano weights, uses seed
  `361004`, trains for exactly one epoch, and differs only by the declared
  brightness/contrast augmentation;
- training dataset SHA-256
  `0e08333bd4652385eb2ccc3cf98fd82c6d0945c61c8484ea4f6af3a82ca33d31`;
- validation manifest SHA-256
  `287ab7dfe0235e5f3a82b7acd82e4eeefbdd58cdc3ff1612a9d5c3112dcafb08`;
- batch size 1, gradient accumulation 8, learning rates, resolution 512,
  overlap 96, visibility 0.80, disabled early stopping and multi-scale
  training, inference threshold 0.31, and NMS IoU 0.40 remain fixed;
- no horizontal flip, geometry, blur, noise, threshold, NMS, data, or
  checkpoint-selection change is allowed.

Run the 36-page smoke gate first. Continue only with complete coverage, a
positive paired per-page F1 confidence interval, and no protected-corpus
regression below -0.01. If it passes, evaluate the frozen candidate without
retuning on the untouched 204 pages and report all 240 development pages.
Qualification, production, paid calls, and pseudo-labels remain unauthorized.

Outcome: the augmentation candidate failed the smoke gate. Its regular
epoch-zero checkpoint SHA-256 is
`baf776bc26862189a4ebe4ab9aaba8fa58f247589a6c3100357e6fba7a774bb3`.
At the frozen threshold, it scored precision 0.982002, recall 0.982241, F1
0.982122, and AP50 0.980266. Summary F1 was +0.000254 above the champion, but
the primary mean paired per-page F1 changed by -0.000993 with 95% CI
[-0.005255, 0.002945]. Protected-corpus deltas were MTH1000 -0.004067,
MTH1200 +0.002767, and TKH +0.002655. Eighteen pages improved, fifteen
regressed, and three were unchanged; a few large MTH1000 and MTH1200
regressions outweighed the small median gain. The required positive confidence
interval was not met, so the untouched 204-page and full 240-page runs were not
executed. Prefer the existing epoch-zero threshold-0.31 champion.


## Kuzushiji cross-script transfer experiment

Goal: test whether source-book-diverse Japanese Kuzushiji pages improve the
same class-agnostic historical-character localization objective without
changing the detector, optimizer, inference policy, or Chinese development
evidence.

Hypothesis: at matched tile and optimizer-update exposure, a 600-page training
mixture containing the current 300 MTHv2 pages plus book-stratified Kuzushiji
tiles improves Chinese MTHv2 localization over a matched mixture containing
the same current pages plus unused MTHv2 tiles. The report supports only
one-class geometric transfer; it does not claim Japanese transcription or
Chinese character recognition improvement.

Immutable controls and selection policy:

- baseline development champion checkpoint SHA-256
  `812d5bfc19f74a301a5eb72a147a35105d700f804948240c783159e8c9747085`;
- both newly trained arms start from RF-DETR Nano weights SHA-256
  `d8d6b9ee57d4d0ed2b1f305163624712a0532cb7bce0c747317984fc5457440d`;
- both arms contain every tile from the existing 300-page MTHv2 training set;
- the matched Chinese control adds unused source-path-hash ranks 181-280 from
  each of TKH, MTH1000, and MTH1200;
- the cross-script arm adds the same exact number of training tiles selected
  deterministically across all eligible CODH Kuzushiji books by book-round-
  robin and page/tile SHA-256 rank; no book, page, box, or score is selected
  using MTHv2 development results;
- CODH Kuzushiji v2 source images and human-final XYWH coordinates are acquired
  only from `https://codh.rois.ac.jp/char-shape/dataset/v2/all.zip`, retained
  with their source SHA-256, attribution, and CC BY-SA 4.0 terms;
- Japanese character identities are discarded only after source validation;
  every positive XYWH box maps to the existing one-class `character` category;
- both arms use seed `361004`, one epoch, disabled early stopping, identical
  tile order derivation, batch size 1, gradient accumulation 8, learning
  rates, resolution 512, 96-pixel overlap, 80% minimum box visibility,
  disabled multi-scale training, gradient checkpointing, and no augmentation;
- both arms use the regular epoch-zero checkpoint, inference threshold 0.31,
  and class-agnostic NMS IoU 0.40;
- the development manifest remains SHA-256
  `287ab7dfe0235e5f3a82b7acd82e4eeefbdd58cdc3ff1612a9d5c3112dcafb08`;
- exact and decoded-image hashes must show zero overlap between all training
  pages and all 240 MTHv2 development pages;
- resulting checkpoints remain local experiment artifacts. Do not distribute
  a Kuzushiji-trained checkpoint until CC BY-SA model-output obligations are
  reviewed.

Frozen data identities:

- Kuzushiji source snapshot SHA-256:
  `99c1fdb6421d65f74793018c2eeaac5734f68c326ec98c7b278cb888fc711656`;
  the manifest is
  `0fcc836a60011f60d394bd6503533fc9595087eda3c310a1585c21abf7f26051`,
  containing 600 pages, 118,018 human boxes, and all 44 source books;
- the 600-page Chinese control dataset record is
  `765dfa9450b4f242fa239baecc08a31a1424b1ced6fb84a06794ed3f0ef1d8f5`,
  with 21,275 training tiles and 308,292 retained boxes;
- the matched transfer dataset record is
  `13a35ddc885606a2d929981a6bcb2bb44df29f27df7e09d07b07a44e617ef1e4`,
  with the original 10,079 MTHv2 tiles plus 11,196 deterministically selected
  Kuzushiji tiles, 21,275 tiles total, and 239,976 retained boxes;
- the control and transfer COCO annotation SHA-256 values are respectively
  `e9afdb86abee85663b88bba53aeabc423c47bae03fb023167416d8c85ad69883`
  and
  `fa4e31514b99e4a0388f40e6c176c6c5a43b15d747ba499e63e4e8fc8b550700`.

Run the frozen 36-page smoke gate first. Continue only with complete coverage,
a positive paired per-page F1 confidence interval for the cross-script arm

protected-corpus regression below -0.01. If it passes, evaluate both frozen

## Full-data one-epoch maximization outcome

The bounded treatment kept the 600-page champion's RF-DETR Nano architecture,
pretrained initialization, seed 361004, one-epoch schedule, 512/96 tiling,
optimizer, and 0.31/0.40 inference policy. It changed only deterministic
in-domain training coverage.

The official training index offered 2,159 pages after reserving the first 80
SHA-256-ranked pages per corpus for development. Two pages had non-positive
official character boxes and one later-ranked page duplicated an earlier image
byte-for-byte. The immutable training manifest records all three exclusions and
contains the remaining 2,156 content-unique pages: 669 TKH, 695 MTH1000, and
792 MTH1200 pages, producing 77,415 tiles and 1,071,028 boxes.

The 36-page smoke gate passed with paired mean page-F1 delta +0.003258 and 95%
bootstrap CI [0.001178, 0.005473]. On all 240 frozen development pages, the
challenger reached precision 0.988074, recall 0.991315, F1 0.989691, and AP50
0.990430. Paired mean page F1 improved by +0.003142 with 95% CI
[0.002025, 0.004403]. MTH1000, MTH1200, and TKH F1 deltas were +0.003138,
+0.004768, and +0.000414. Checkpoint SHA-256 is
`f77d91bba64891a79f70fbabaeaca95e104a1d94c2db46fe7d20b41012e95f8c`.
This is a frozen development winner. It did not inspect the official test set
or authorize qualification, proposal, promotion, or production changes.

## Candidate contract

One JSON object per line:

```json
{"case_id":"mthv2/TKH/0001_031_27_27","characters":[{"bbox":[1346,642,38,28],"score":0.99}],"latency_seconds":2.4}
```

`case_id` and `characters` are required. Each character requires a positive
`[x, y, width, height]` bounding box; `score` defaults to 1.0. No character
label or page transcription is required. A prediction file must cover every
selected case exactly once. Duplicate, unknown, missing, or geometry-free
cases fail scoring.

## Metrics

`benchmark.py` reports:

- unlabeled character-detection precision, recall, and F1 at IoU 0.50;
- AP50 using prediction confidence;
- predicted, true-positive, false-positive, and false-negative counts;
- case coverage;
- paired per-page detection-F1 deltas with a fixed-seed bootstrap confidence
  interval;
- the same metrics for each protected source corpus.

Character labels present in source data may be retained as optional diagnostics,
but they do not affect the localization objective. Scores are micro-aggregated
over character instances. A candidate with missing localization evidence
fails rather than receiving a successful zero.

## Autoresearch loop

One cycle changes one behavioral lever:

1. write an observable localization-failure hypothesis;
2. record the exact baseline fingerprint and challenger fingerprint;
3. run the 36-page smoke slice;
4. reject immediately on missing pages, a negative paired F1 interval, or a
   protected-slice regression greater than 0.01 F1;
5. run all 240 development pages only if the smoke gate passes;
6. compare paired per-page detection-F1 deltas, AP50, and protected corpora;
7. keep the challenger only when the improvement is reproducible and no hard
   gate regresses;
8. record the result in `experiments/LOG.md`; delete losing code and retain
   immutable score artifacts;
9. run the 800-page qualification split only for a development winner;
10. after external qualification, run the 28-folio production protection set
    before any formal Factory proposal.

Never tune thresholds, preprocessing, or segmentation on qualification pages.
Never use a model judge or transcription output in place of character-location
ground truth. Never move a candidate into the production recipe from this
experiment lane; production still requires the formal
candidate/suite/report/proposal/canary/promotion flow in `docs/OPERATIONS.md`.

## First experiment sequence

1. Use the current `separation2` geometry as the frozen baseline.
2. Measure per-page misses, multi-character merges, character splits, junk
   detections, and frame or marginalia detections.
3. Rank the worst pages by detection F1 and inspect their overlays.
4. Choose one causal geometry or gate change from the dominant error mode.
5. Run the 36-page smoke comparison and retain the challenger only if the
   paired localization gate passes.
6. Do not add or benchmark a recognizer while this experiment is active.
