# Pal.lat.1985 - Trionfi Allegorical Cycle

## Discovery

**Status**: GENUINELY UNSTUDIED - First scholarly documentation

This manuscript was identified through our Vatican metadata scanning system as falling through the cracks of three different cataloging projects. The catalogers themselves used question marks in the description.

**Original catalog entry**: "Rappresentazioni allegoriche, riproduzioni (?) di arazzi (?)"
(Allegorical representations, reproductions (?) of tapestries (?))

**What it actually is**: A complete illustrated Trionfi (Triumphs) cycle in the Petrarchan tradition, NOT a "Triumph of Death" as some catalogs suggest.

## Contents

16th century Italian pen drawings (ff. 1v-10r) depicting allegorical triumphal processions:

| Folio | Content |
|-------|---------|
| 1v-2r | **Triumph of Fame/Mars** - Military glory, chariot pulled by lions |
| 2v-3r | Procession of famous warriors (Nine Worthies tradition) |
| 3v-4r | **Triumph of Avarice/Plutus** - Greed, chariot pulled by wolves |
| 4v-5r | Procession continues |
| 5v-6r | **Triumph of Learning** - Scholars and philosophers |
| ... | (Analysis in progress) |

## Significance

1. **Never studied** - Falls in cataloging gap between Stevenson (1886), Metzger (2002), and French catalog (2025)
2. **Complete cycle** - Multiple triumphs with labeled figures
3. **Iconographic value** - Named historical figures allow precise identification
4. **Art historical interest** - 16th century Italian drawing style, possible tapestry connection
