## CRITICAL: THE MINIM PROBLEM

In Gothic textualis, these letters are made of identical vertical strokes (minims):
- **i** = 1 minim (often with dot)
- **u, n** = 2 minims each
- **m** = 3 minims
- **w** (rare in Latin) = 3 minims

The word "minimum" appears as 10 indistinguishable vertical strokes.

**Strategy**: Count minims, then test possible letter combinations against Latin vocabulary.

### Minim Confusion Examples
| Looks like | Actually is | How to verify |
|------------|-------------|---------------|
| "inuicies" | **invenies** | "invenies" = "you will find" (common in recipes) |
| "inuies" | **invenies** | Same - missing minim for the "n" |
| "unium" | **vinum** | Context: is wine mentioned? |
| "mim" | **num** or **min** | Check which makes Latin sense |

## GOTHIC SCRIPT LETTER CONFUSIONS

| Confused pair | How to distinguish |
|---------------|-------------------|
| **c / t** | t has crossbar extending right |
| **c / e** | e has horizontal tongue inside |
| **f / long-s (ſ)** | f has crossbar both sides; ſ only left |
| **u / n** | IDENTICAL - use context |
| **i / l** | l is taller |
| **a / o / u** | Round letters - check context |
| **d / cl** | Uncial d is round; cl has gap |

### Long S Rules
- **Word-initial**: long s (ſ)
- **Word-medial**: long s (ſ)
- **Word-final**: round s (s)
