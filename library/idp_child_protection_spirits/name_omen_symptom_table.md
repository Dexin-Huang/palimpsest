## Stable Pattern

Across the surviving six sides, the recurring formula is:

1. goddess named, usually as a transliteration
2. animal or figure form visible in the painting
3. omen or dream trigger
4. child symptom or affliction
5. ritual action, usually sacrifice / appeasement
6. auspicious outcome formula

## Current Use

This table should be treated as:

- a working normalization layer for the surviving leaves
- a guide for later packet completion
- a target structure for scouting adjacent IDP witnesses in the same tradition

It is not yet a final philological reconstruction. Several names, omen clauses, and prescriptions remain damaged or only partly legible.
