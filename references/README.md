# References

This folder is a small working library of upstream projects that are useful
reference points for Palimpsest.

The goal is not to mirror those repos or track them exhaustively.

The goal is:
- keep a stable shortlist of relevant upstream work
- record why each repo matters
- give future sessions one place to start when looking for patterns

## Files

- `github_repos.md`
  Human-readable index of relevant GitHub repos.

- `github_repos.json`
  Machine-readable manifest for tooling, agents, and future automation.

## Inclusion Rules

Add a repo here when it is one of:
- a direct architectural reference
- a useful implementation reference
- a benchmark or evaluation reference
- an SDK or orchestration reference we may build against

Prefer:
- official upstream repos
- actively maintained repos
- repos with a clear relevance to Palimpsest's core work

Avoid:
- random forks unless the fork itself is the real reference
- one-off demos with no direct value to the project
- generic lists of unrelated AI repos
